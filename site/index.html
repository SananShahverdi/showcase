Multi-Task PPO Lab

One neural network learns two different jobs: reaching a goal, and fetching a key before opening a door. PPO is written from scratch, and the agent is tested on layouts it never saw during training, beside a random agent and the optimal path.

Simulation · Queueing theory

NeuroFlow

A network of queues, verified against M/M/1 and M/D/1 theory, asks when learned routing beats shortest paths. Drag the load to where the busiest link saturates, and past it.

Mean delivery time, log scale, 3 seeded runs per point. One time unit is the mean service time.

Forecasting · Statistics

Quant Research Lab

Ten years of daily AAPL prices, walk-forward evaluation, and a significance test against a random walk. The honest result is the interesting one: no model beats the random walk, and the trading signal trails buy and hold.

    03 · Practice

    How the work is checked.

    1. i

      Test against ground truth

      Simulators are checked against queueing formulas, forecasts against look-ahead leaks, persistence against real container restarts, and interfaces against real browser workflows.

    2. ii

      Report the baseline

      Every learned model is shown beside a naive or optimal reference, on held-out data, including when the comparison is unflattering.

    3. iii

      Label the scope

      Simulations, synthetic data, and offline providers say so in the interface and the documentation. Nothing is presented as deployed when it is not.

    4. iv

      Ship the whole thing

      An API, an interface, persistence, Docker packaging, documentation, and continuous integration: a project is finished when someone else can run it.
