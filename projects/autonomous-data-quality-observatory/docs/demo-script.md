# Demo Script

## Recruiter-Friendly Walkthrough

1. Open the README and explain the business problem: Profile datasets, detect quality regressions, explain failures, and open remediation issues.
2. Show the architecture diagram and identify the main modules.
3. Start API and console using the README commands, load clean baselines, then introduce and observe real record drift.
4. Load seeded sample data.
5. Execute the primary workflow.
6. Show stored evidence: logs, metrics, audit records, reports, or model evaluation.
7. Explain one tradeoff and one failure mode.

## Expected Demo Evidence

- Terminal output or dashboard screenshot.
- Persisted sample result.
- Test output.
- Architecture and algorithm notes.

## Demo Claim

Keep the demo factual. Say what runs locally, what is simulated, what is synthetic, and what still needs production hardening.
